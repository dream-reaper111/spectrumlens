# Hardware support

`hardware` reports that offline IQ analysis is available. SoapySDR import presence is detected, but no SDR device is reported available without enumeration and validation. SoapySDR, RTL-SDR, HackRF, LimeSDR, and PlutoSDR acquisition are not integrated in this milestone. No USB receiver was accessible in this environment. RTL-SDR is not assumed to receive 2.4 GHz BLE. Frequency and sample-rate limits in the CLI are file processing bounds and do not claim any hardware tuning range. No transmit operations are exposed.
